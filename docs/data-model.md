# Data model

PostgreSQL Flexible Server. Schema is bootstrapped idempotently by `db.ensure_schema()` on every service start.

## Tables

### `devices` — fleet registry

| Column | Type | Notes |
|--------|------|-------|
| `id` | TEXT PK | e.g. `dev-000` |
| `name` | TEXT | e.g. `HVAC-000` |
| `room` | TEXT | room type (lobby, office-1, …) |
| `setpoint_c` | NUMERIC | default 22.0; PATCH-able from UI |
| `created_at` | TIMESTAMPTZ | default `now()` |

`upsert_device` refreshes `name`/`room` on conflict but **never overwrites a user-set `setpoint_c`**.

### `device_telemetry` — high-cardinality stream

| Column | Type |
|--------|------|
| `id` | BIGSERIAL PK |
| `device_id` | TEXT FK → devices.id ON DELETE CASCADE |
| `ts` | TIMESTAMPTZ default `now()` |
| `occupants` | INT |
| `outdoor_temp_c` | NUMERIC |
| `outdoor_humidity` | NUMERIC |
| `indoor_temp_c` | NUMERIC |
| `setpoint_c` | NUMERIC |
| `energy_w` | NUMERIC |
| `action` | TEXT (`idle | cool | heat`) |

Index: `device_telemetry(device_id, ts DESC)`.

### `jobs` — orchestration

| Column | Type | Notes |
|--------|------|-------|
| `id` | UUID PK | generated by API |
| `type` | TEXT | `forecast` or `rl` |
| `status` | TEXT | `queued | running | succeeded | failed` |
| `message_id` | TEXT | Service Bus message id |
| `created_at` | TIMESTAMPTZ |  |
| `started_at` | TIMESTAMPTZ |  |
| `finished_at` | TIMESTAMPTZ |  |
| `error` | TEXT | truncated traceback when failed |

Index: `jobs(type, status)`.

### `forecast_results`

| Column | Type |
|--------|------|
| `job_id` | UUID PK FK → jobs.id ON DELETE CASCADE |
| `dataset` | TEXT (device id or `synthetic-*`) |
| `horizon` | INT |
| `forecast` | JSONB (list of medians) |
| `mape` | NUMERIC nullable |
| `created_at` | TIMESTAMPTZ |

### `rl_results`

| Column | Type |
|--------|------|
| `job_id` | UUID PK FK → jobs.id |
| `algo` | TEXT (`PPO` / `DQN`) |
| `total_steps` | INT |
| `mean_reward` | NUMERIC |
| `reward_curve` | JSONB |
| `policy_uri` | TEXT (`blob://artifacts/rl/{job_id}/policy.zip`) |
| `created_at` | TIMESTAMPTZ |

## Helper functions (`src/common/db.py`)

| Function | Purpose |
|----------|---------|
| `connect()` | Context manager. Uses `DefaultAzureCredential` to mint a Postgres AAD token, unless `PG_USE_PASSWORD=1` |
| `ensure_schema()` | Creates all tables and indexes if missing |
| `upsert_device(id, name, room, sp)` | Idempotent device registration |
| `fetch_setpoints()` | `dict[id → setpoint_c]` for the simulator |
| `insert_telemetry(...)` | Append a telemetry row |
| `recent_indoor_series(device_id, limit=256)` | Latest N indoor temps (chronological) for forecasting |
| `enqueue_job(job_id, type, message_id)` | Pre-insert in `queued` (called by API on POST) |
| `insert_job(job_id, type, message_id)` | Transition to `running` (called by worker) |
| `finish_job(job_id, status, error=None)` | Mark `succeeded` or `failed` |
| `save_forecast(...)` | Upsert into `forecast_results` |
| `save_rl(...)` | Upsert into `rl_results` |

## Connection auth

In-cluster: pods get an AAD token via Workload Identity, exchanged for a short-lived Postgres password. The Postgres user is the UAMI display name (`aidemo-workload-id`).

Local: set `PG_USE_PASSWORD=1` and `PGPASSWORD=...` to use a regular password instead.
